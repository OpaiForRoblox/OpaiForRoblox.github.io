The original is closed source. This isn’t.

Adjust ships as a compiled binary. You run it, and you take its word for what it does on your machine.

OpenAdjust is that same client as plain Java. Every module, every command, the ClickGUI, the HUD and the scripting API are in the repo for you to read, build and modify.

It is based on Adjust’s October 16th build, changelog version 96.

Build it yourself

The whole client builds and runs with the Gradle wrapper that ships in the repo.

JDK 21
Gradle’s Java toolchain resolves it for you.
Windows x64
The LWJGL 3.3.3 Windows natives and opus.dll are bundled. For other platforms, change lwjglNatives in build.gradle.

  1. Get the source

    git clone https://github.com/yxzeroo/openadjust

  2. Run it

    .\gradlew.bat runClient

    Launches the client directly in offline dev mode. You can also run launch_client.bat.

  3. Build the JAR

    .\gradlew.bat build

    The JAR ends up in build/libs/adjust-client-1.8.9.jar.
